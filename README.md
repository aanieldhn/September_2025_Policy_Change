This is the publicly available GitHub repository for the manuscript "Unintended Shifts in High-Priority Adult Heart Transplant Listings after the OPTN’s September 2025 Policy Change." This repository includes the complete statistical code necessary for producing all statistical analyses, figure creation, and table design in this paper. The RMD on this website is an updated version of that which can be found on the first author's (Christian Ramos) personal GitHub repository here: https://github.com/chrisramos017/ListingBehaviorChangesSep2025.

To reproduce the analyses, one must have access to the Organ Procurement and Transplantation Network's Standard Transplant Analysis and Research (STAR) files, which can be obtained through data use agreements (typically requiring a priori IRB approval) with the OPTN. If you have any questions about the analyses, please reach out to the corresponding author (Daniel Ahn) at danielahn1996@gmail.com.
